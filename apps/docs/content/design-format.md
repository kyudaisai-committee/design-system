各デザイン仕様では、見た目の特徴と、その表現を使う場面を説明しています。システムの仕様は画面に共通する基準、年度別ホームページの仕様は各年度の表現を参照するための資料です。

## 必要な項目から読む

仕様はDESIGN.md形式で、次の順に構成しています。英語の見出しは形式上の共通名です。

| 見出し            | 内容                                   |
| ----------------- | -------------------------------------- |
| Overview          | デザインの考え方と特徴                 |
| Colors            | 色の役割と組み合わせ                   |
| Typography        | 書体、文字サイズ、太さ、行間           |
| Layout            | 情報の順序、配置、余白、画面幅への対応 |
| Elevation & Depth | 面の重なり、影、動き                   |
| Shapes            | 角丸、線、輪郭、装飾の形               |
| Components        | 部品の用途と使い分け                   |
| Do's and Don'ts   | 採用する表現と避ける使い方             |

色や寸法は、用途と併せて確認してください。たとえば、背景を区切る薄い線と、入力欄を見分けるための線では、必要な濃さが異なります。

## 値の名前と役割

色・文字・余白・角丸に名前を付けた共通の設定値を「デザイントークン」と呼びます。システムでは、主な操作に使う色を`primary`、本文色を`foreground`のように、役割に応じて管理しています。

Markdown版の先頭には、設定値をまとめたYAMLがあります。`colors`は色、`typography`は文字、`spacing`は余白、`rounded`は角丸を表します。`dark-`で始まる色はダークモード用です。年度別の値は各ページの表現を説明するもので、システムの共通値とは分けて扱います。

## 実際の表示と操作を確認する

数値だけでは、長い日本語の折り返しや、処理中のボタンの振る舞いまでは分かりません。[Storybookの部品一覧](/storybook/?path=/story/overview-component-catalog--browse)で表示と操作を確認し、[画面と操作](./system/patterns.md)と組み合わせて設計してください。

Webへの導入方法は[Webへの組み込み](./system/implementation.md)、画面幅やOSによる違いは[Web・アプリの設計](./system/native.md)にまとめています。
