---
title: 進行状況と履歴
description: 今どこまで進んだか、何が起きたか、いつまでに対応するかを伝える。
---

手続きの現在位置、過去に起きた出来事、期限や予定は、それぞれ分けて表示します。申請の詳細なら、上部に「審査中」を示し、その下に提出期限や審査の進行状況、過去の提出・差し戻しを配置します。

## 知りたいことに合わせて部品を選ぶ

| 利用者が知りたいこと | 部品 | 表示例 |
| --- | --- | --- |
| 今どこまで進んだか、次は何か | [ProcessSteps](/storybook/?path=/docs/components-processsteps--docs) | 提出 → 審査 → 審査結果 |
| いつ、誰が、何をしたか | [Timeline](/storybook/?path=/docs/components-timeline--docs) | 第1版の提出、差し戻し、第2版の再提出 |
| いつまでに、いつ行われたか | [DateDetails](/storybook/?path=/docs/components-datedetails--docs) | 提出期限、提出日時、通知予定 |
| 現在の状態だけを知りたい | [StatusBadge](/storybook/?path=/docs/components-statusbadge--docs) | 一覧の「審査中」 |
| なぜ止まっているか、何をすべきか | [Notice](/storybook/?path=/docs/components-notice--docs)と関連する操作 | 不足資料の説明と再提出ボタン |

ProcessStepsは順序が決まっている手続きに使います。順不同で行える作業はタスク一覧、並列の審査は担当別の表示にします。ファイル送信のように量を測れる処理には、[Progress](/storybook/?path=/docs/components-progress--docs)を使ってください。

## 現在の段階を線と文字で示す

現在の段階は直線と太字で強調し、「審査中」「結果待ち」などの状態名を添えます。横並びでは見出しの下、縦並びでは左側に線を置きます。背景の塗りつぶしやカード状の囲みは使いません。

段階名は「提出」「審査」のように短くし、説明には必要な対応を記載します。説明が長い場合や段階が多い場合は、広い画面でも縦並びを選びます。横並びは表示領域が40rem未満になると縦並びに切り替わります。

アイコンは出来事の意味に合わせます。「提出」は進行状況でも履歴でも同じアイコンを使い、完了したという理由だけでチェックに置き換えません。現在位置や結果は文字でも伝えます。

## 分岐する結果を一列に並べない

承認、差し戻し、却下は、順に通過する段階ではありません。最後の段階を「審査結果」とし、確定した結果をそこに表示します。

| 場面 | 進行状況の表示 |
| --- | --- |
| 審査中 | 「審査」を現在の段階にし、「審査結果」は結果待ちにする |
| 承認・却下で終了 | 「審査結果」を完了にし、結果名を添える。現在の段階は設けない |
| 差し戻し後の修正待ち | 「修正・再提出」を現在の段階にし、「再審査」を次に置く |

「完了」は段階が終わったことを意味します。承認か却下かは、結果名と色で別に示してください。差し戻し前の提出や審査は履歴に残します。

## 履歴は、起きた出来事を順に並べる

Timelineには、提出、差し戻し、再提出などの出来事を日時とともに並べます。担当者、提出版、理由は、関係する出来事に添えます。

古い順か新しい順かを決め、見出しの近くに表示します。通知の送信や担当変更が最後に記録されていても、それが現在の審査状態とは限りません。現在の状態は別に示し、将来の予定を出来事の履歴に混ぜないようにします。

出来事の発生時刻が不明な場合は、画面を開いた時刻で代用せず「時刻の記録なし」と記載します。時刻を表示する場合は、日本時間などの基準も示してください。

## 期限と予定は、関係する段階に添える

提出期限・提出日時は「提出」、通知予定日は「審査結果」に添えます。画面幅や並び方が変わっても、この対応を保ちます。

期限を延長した場合は、現在の期限を先頭に太字で表示し、「延長済み」と添えます。標準期限はその下に通常の太さで示します。同じ期限なら一件だけ表示してください。

| 項目 | 表示例 |
| --- | --- |
| 提出期限 | 10月20日 17:00（延長済み） |
| 標準期限 | 10月15日 17:00 |
| 通知予定 | 未定 |

値を取得できない場合は「未確認」、決まっていない場合は「未定」とします。「期限なし」とは区別してください。予定日を過ぎても、自動で実績や完了に変えません。提出期限を延長しただけで、審査や通知の予定をずらすことも避けます。

## 読み込みや更新の状態を伝える

取得中は読み込んでいることを示し、失敗した場合は説明と再試行の操作を表示します。まだ結果を取得していない状態を「履歴なし」と扱わないでください。

更新時は「再提出を受け付けました」のように短く結果を伝え、読み上げで履歴全体を繰り返さないようにします。差し戻し理由や次の行動は、すぐに消える通知だけに置かず、画面に残します。

引数と使用コードは、各部品のStorybookを参照してください。
