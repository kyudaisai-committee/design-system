Webは`@kyudaisai/ui`、React Nativeは`@kyudaisai/ui-native`から読み込みます。両方で同じ対象・値・状態を渡し、画面の幅とOSの操作に合わせて表示します。部品は表示と入力を扱い、認可、公開版、期限、保存、受付の確定は利用側で確認します。

## 用途から部品を選ぶ

| 用途         | 部品                                                                              | 操作・表示                                                                 |
| ------------ | --------------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| 本文         | MarkdownContent                                                                   | 見出し、リンク、箇条書き、引用、表、コード、許可された画像、添付用の領域   |
| 画像         | PublicImage                                                                       | 代替説明、読込中、失敗、利用不可、期限切れ                                 |
| 写真一覧     | ImageGallery                                                                      | 枚数・共有範囲、一覧、拡大、閉じる                                         |
| 地図         | MapView                                                                           | 拡大・縮小、上下左右の移動、会場一覧による選択                             |
| 配置編集     | MapEditor                                                                         | 場所の追加・削除、名称と位置の変更                                         |
| 結果         | ResultChart                                                                       | 棒グラフ、順位・数値・単位・注記。狭い画面では縦に表示                     |
| 会話         | ConversationList、MessageList、ThreadPanel、MessageResultList、ConversationLayout | 会話、未読、スレッド、検索・保存の結果、媒体に応じた表示切替               |
| 投稿         | MessageComposer、MentionPicker                                                    | プレーンテキスト入力、添付の状態、メンションの宛先、送信中・失敗・結果不明 |
| QRの読取り   | QrScanner                                                                         | 明示的な開始、カメラの許可、読取り、停止、再開                             |
| フォーム作成 | FormBuilder                                                                       | 項目追加・編集・並替え・複製・削除、条件、構造のプレビュー                 |
| 条件         | ConditionEditor                                                                   | AND・OR・NOTのグループ、項目・比較・値の入力                               |
| 内容比較     | ComparisonView                                                                    | 前後の値、追加・削除・変更なしの表示                                       |
| 勤務配置     | AssignmentBoard                                                                   | 枠ごとの人数、不足・超過、配置先の選択、固定、競合理由                     |
| 写真の選択   | PhotoPicker                                                                       | 選択、端末標準の切り抜き、取消、選択解除                                   |

各部品の使用例は[コンポーネント一覧](/storybook/?path=/story/overview-component-catalog--browse)から開けます。空、無効、処理中、失敗は該当する部品のStoryで切り替えます。

## 本文と画像の表示範囲を先に確認する

`MarkdownContent`にHTMLの実行機能はありません。HTMLは文字として表示します。リンクにはHTTP・HTTPS、同一サイト内の絶対パス、ページ内参照だけを許可します。Nativeでサイト内のパスを開く場合は`onOpenLink`でアプリの遷移へ渡してください。

本文の画像は自動取得しません。`resolveImage(url, alt)`で確認済みの`ImageAsset`を返した段落内の画像だけを表示します。それ以外は代替説明を表示します。画像の有効期限にはUnixミリ秒の`expiresAt`を渡し、権限が失効した場合は`state="unavailable"`へ更新します。利用不可・期限切れでは写真、説明、注記、拡大操作を隠します。端末内URIや認可済みURLは、信頼できる`resolveSource`で解決します。部品の表示制御だけで、取得APIの認可を代替しないでください。

添付の認可・検査・保持期限は利用側で照合します。本文中の任意URLを添付IDとして扱わず、確認済み添付への導線を`attachments`へ渡します。

## 保存・確定と入力を分ける

`MessageComposer`はEnterで改行し、送信ボタンだけで送信します。Webでは日本語変換中の送信を止めます。`state="unknown"`では本文を保持して新しい送信を止め、結果の再照会は利用側で行います。

`FormBuilder`の型はUI用です。公開APIの定義と同一とは扱わず、所有領域で変換・検証します。複製には利用側の`createId`を渡し、内部の項目参照も新しいIDへ対応させます。標準プレビューは項目構造を確認する表示で、実際の条件分岐や回答操作を確認する場合は`renderPreview`へ回答部品を渡してください。条件の評価・循環検査・公開判定は所有APIで実施します。

`MapEditor`は0〜100の相対座標を編集します。地図の拡大率を変えても保存値は変わりません。Web・Nativeのどちらも数値入力で配置でき、ドラッグだけに操作を限定しません。背景の地図と場所の対応は利用側で用意し、位置情報の権限は要求しません。

`AssignmentBoard`は渡された配置を表示します。固定された項目の移動を止め、人数の不足・超過と競合理由を表示します。資格や時間の重複を判定する計算機能は持たず、移動後の検証・保存は利用側で行います。Nativeへ管理画面を搭載するかどうかは、利用するアプリの仕様に従ってください。

## カメラは読取りを始めるときだけ使う

`QrScanner`は開始ボタンを押すまでカメラを起動しません。WebではZXing、NativeではExpo Cameraを使います。読取り後はカメラを停止し、`onRead`へ値を渡します。照合中に次の読取りを開始せず、値を画面やログへ表示しません。カメラが読めたことと、受付が確定したことを区別してください。

画面から離れるときは`active={false}`を渡します。アプリやタブが背景へ移ったときも停止します。WebにはHTTPSまたはlocalhostとカメラを許可するブラウザー設定が必要です。Nativeには`expo-camera`を追加し、config pluginでカメラの目的を説明します。音声を使わない場合は`recordAudioAndroid: false`にします。[Expo Camera](https://docs.expo.dev/versions/latest/sdk/camera/)

## 写真の切り抜きは端末の画面へ委ねる

Nativeの`PhotoPicker`はExpo ImagePickerの編集画面を開き、位置・拡大率の独自スライダーは表示しません。iOSの標準切り抜きは正方形、Androidは`aspect`で指定した比率に対応します。切り抜かず選ぶ操作も用意し、取消時は前の写真を保持します。[Expo ImagePicker](https://docs.expo.dev/versions/latest/sdk/imagepicker/)

写真の選択だけを理由に広範なフォトライブラリー権限を要求しません。Webには共通のOS編集APIがないため、写真アプリで編集した画像を選ぶ方式です。部品で画像を自動的に中央から切り抜くことはありません。固定の比率が必要な場合は、その条件を選択前に説明し、受信した寸法を利用側で検証します。

Webの`onPick`には画像情報と元の`File`を渡します。一時URLは選択の置換・解除・部品の破棄まで利用でき、保存する場合は`File`を使います。Nativeは選択した画像のURIを渡します。戻された一時ファイルの保持・消去、AndroidでActivityが再作成された場合の結果回復、アップロード・保存は利用側で扱います。選択解除を提供するときは`onClear`で利用側の選択状態も更新してください。
